# ⚡ Pokemita FullStack

Simulador de combates Pokémon competitivos del meta Gen 9 OU.

## 🛠️ Stack

- **Backend:** Node.js + Express + pokemon-showdown
- **Frontend:** React + Vite + Tailwind CSS + Zustand + React Router
- **Testing:** Jest (backend), Vitest (frontend)

## 📁 Estructura

\`\`\`
Pokemita-FullStack/
├── backend/    API REST + motor de batalla
└── frontend/   Interfaz React
\`\`\`

## 🚀 Cómo correr

### Backend
\`\`\`bash
cd backend
npm install
npm run dev
\`\`\`

### Frontend
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`

Abre http://localhost:5173

## ✨ Features

- Batallas IA vs IA automáticas
- Combatir contra IA con equipo personalizado
- Team Builder con todos los Pokémon del meta
- Sistema de mochila (pociones, revivir)
- Wiki integrada
- Login/Register con persistencia
